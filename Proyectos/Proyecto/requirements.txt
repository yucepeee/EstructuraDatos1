## Requisitos e instalación

- Python 3.10 o superior.
- Flet.

El archivo `requirements.txt` está vacío actualmente; instala Flet directamente:

```bash
python -m venv .venv
```

En Windows:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install flet
```

En macOS o Linux:

```bash
source .venv/bin/activate
python -m pip install flet
```
